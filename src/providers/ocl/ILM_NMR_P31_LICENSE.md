# Ilm-NMR-P31-derived ³¹P HOSE shift statistics: attribution and licenses

The bundled table `src/providers/ocl/ilm-nmr-p31.database.json` is derived from
**Ilm-NMR-P31 v3.0**. It was built from the GitHub repository
`clacor/Ilm-NMR-P31` at commit `ead6f914d2bdfb60e4befea72ea503d32978d358`, whose
content is identical to v3.0 on Zenodo. Three notices apply: the CC BY 4.0
attribution for Ilm-NMR-P31 v3.0, the CC BY 4.0 attribution for NMRexp, and the
BSD-3-Clause license text of the GitHub copy. The data is redistributed with the
author's permission (owner, 2026-11-20).

**Change notice.** Changes were made. The original records were filtered
(environments with fewer than five observations were dropped) and transformed into
aggregated HOSE environment shift statistics. The table holds no structures and no
original records. It is not endorsed by the dataset authors.
