# Report 0017 — M20: NMR results UX (real spectrum, draggable panel, copy/export)

**Date:** 2026-07-10
**Worktree:** `~/Documents/programming/chemdraw-nmr` @ `codex/nmr-plugin`
**Extends:** [ADR-0015](../decisions/0015-core-owned-interactive-panel-sections.md) (core-owned interactive figure)

## Ask (user, comparing our output to ChemDraw's)

1. The results box was fixed in the corner — make it draggable.
2. Results should be copy-paste ready (as SVG).
3. Export to a file NMR software (MestReNova/TopSpin) can open.
4. The spectrum should look like a real spectrum, not jagged sticks.

## What shipped

- **M20a — realistic spectrum** (commit `2636d55b`). Replaced the raw vertical `<line>` sticks with a
  single continuous **summed-Lorentzian trace** (per-pixel `<path>`), autoscaled to the tallest visible
  peak, with a pixel-floor linewidth so peaks stay visible at full zoom and multiplets resolve smoothly
  as you zoom in — the ChemDraw look (verified: benzophenone aromatics resolve as clean triplets).
  Hovering a peak overlays its own highlighted trace. Confidence indication moved to the structure's
  shift labels, colored **good / medium / rough** with a legend (exactly ChemDraw's pattern), reusing
  the M17a confidence tiers.
- **M20b — draggable panel** (commit `fa857189`). Grab the results header to move the whole popup;
  window-level pointer listeners keep the drag alive off the header, a button press never starts a
  drag, and it's clamped so it can't be lost off-screen.
- **M20c — copy SVG + export JCAMP-DX** (commit `b3b8a538`). "Copy SVG" writes a self-contained SVG
  (inlined styles + xmlns) to the clipboard, paste-ready. "Export" downloads a **JCAMP-DX 5.01 peak
  table** (`.jdx`) with nucleus / observe-frequency headers — the format MestReNova, TopSpin, and ACD
  open directly. Serialization + JCAMP live in a pure, unit-tested `spectrumExport` module.
