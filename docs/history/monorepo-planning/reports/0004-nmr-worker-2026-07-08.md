## Key design decisions

**Testable core split.** The message logic lives in `nmrWorkerCore.ts` (pure);
`nmrWorker.ts` only wires `globalThis`. So supersession, cancellation, and error
normalization are unit-tested with a controllable predictor and fake timing —
no real Worker required — while `nmrWorker.ts` stays trivial.

**Two-layer cancellation (ADR-0012 groundwork).** The worker aborts the prior
provider run (`AbortSignal`) *and* the client ignores a result whose request is
no longer active. The provider's `NMR_PREDICTION_CANCELLED` (review fix #2)
flows through as a `cancelled` response, so a superseded rerun rejects as
cancellation, never as a failure — exactly what the panel-close/supersession
lifecycle (M9) needs.

**Lazy worker.** Unlike the conformer client (which spawns eagerly and defers
client creation to idle), the NMR client spawns the worker only on first
`initialize`/`predict`. NMR is rarely used, so creating the client at startup
costs nothing until a real prediction.
