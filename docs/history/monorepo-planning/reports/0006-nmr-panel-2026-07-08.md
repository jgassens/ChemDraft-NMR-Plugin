## What shipped

**Stick spectrum (plugin package).** `report/stickSpectrumSvg.ts`
(`renderStickSpectrumSvg`) draws resonances as vertical sticks on a **reversed**
ppm axis (high→low, NMR convention), stick height by equivalent-nuclei count. It
is a self-contained SVG *string* — own white plot background, explicit colors,
no CSS vars or script — because panel SVGs render through an `<img>` data URL
(isolated, theme-independent, script-inert). `composePredictionReport` adds it as
the first `svg` section above the table.

**Staleness (D-09).**
- `plugin-api`: `PluginPanelReportSchema` gained an optional `source: { objectId, sourceFingerprint }`.
- The NMR result report stamps `source` from the selected molecule.
- Desktop `computeObjectFingerprint(document, objectId)` recomputes the fingerprint from the live document (independent of selection); `MainWindow` compares it to `report.source.sourceFingerprint` and passes `stale` to `PluginPanelSurface`, which shows a banner ("This result may be out of date…") and a `data-stale` marker. Editing or deleting the molecule flags the open panel.

**Panel-close lifecycle (ADR-0012).**
- `plugin-host`: `RegisterPluginOptions.onPanelClosed?(panelId)`, stored per plugin, invoked by `notifyPanelClosed(pluginId, panelId)`, dropped on unregister.
- Desktop `PluginPanelController.closePanel()` calls `host.notifyPanelClosed(...)`.
- The NMR plugin's `createNmrRegistration` shares one `AbortController` across the command and `onPanelClosed`: a new prediction supersedes (aborts) the prior; closing the panel aborts the active one. `predictSelectedStructure` forwards the signal to the predictor **and** re-checks `signal.aborted` after the predict resolves, so a late result neither writes a record nor resurrects a dismissed panel.

Tests (+11): `stickSpectrumSvg` (4: self-contained/inert, one stick per resonance, reversed axis, empty), `register` (2: close aborts the in-flight prediction / ignores other panels), `composePredictionReport` (+2: svg section + source stamp), plugin-host `notifyPanelClosed` (1), desktop `computeObjectFingerprint` (2), and `PluginPanelSurface` stale banner (1).

## Decisions / deviations

- **ADR-0012 & D-09 resolved and shipped.**
- The "don't reopen a closed panel" guarantee is enforced by **cancellation + a post-predict `signal.aborted` check** in the command, rather than reopen-suppression logic in the controller — simpler and it covers the real race (the fixture resolves fast). Documented.
- Report SVG stays a string rendered via `<img>` (the settled repo panel model, ADR-0004); no inline SVG injection.

## Unresolved risks / carried forward

1. Staleness compares against the live document by object id; if an object id is reused for a different molecule the fingerprint still changes (structure differs), so it degrades safely to "stale."
2. Panel-close cancellation is proven with the fixture; the worker path uses the same `AbortSignal`/supersession machinery validated in M7.
3. Bundle size (~1.16 MB worker, OCL) unchanged — lazy; M10 territory.
