4. Export did nothing when clicked.

## What shipped (commit `c06e97a3`)

- **Export fix (was a no-op).** A blob `<a download>` does nothing in the Tauri webview.
  `saveTextFile()` now uses the app's native path — `@tauri-apps/plugin-dialog` `save()` +
  `plugin-fs` `writeTextFile()` — on desktop, and the blob download on web.
- **Copy → image + SVG.** `copySpectrumToClipboard()` rasterizes the spectrum to a PNG (offscreen
  canvas) and writes a `ClipboardItem` with **`image/png`** (pastes as an image into Word/Slack/docs)
  **and** `text/plain` = the SVG source (vector editors get the scalable original). Falls back to
  SVG-text where `ClipboardItem` is unavailable. (macOS's native text-clipboard command can't carry
  real HTML/image types, so the browser `ClipboardItem` path is the portable one.)
- **Two-finger horizontal pan.** The wheel handler pans on a deltaX-dominant event and still zooms on
  vertical scroll; shared `panByPixels()` with the drag handler.
- **Full-size popup.** A "Full size" toolbar button opens the spectrum enlarged in a modal —
  **portalled to `<body>`** so the draggable panel's `transform` can't offset a fixed overlay — hosting
  a fresh full-size interactive figure. Esc / Close / backdrop click dismiss it.
