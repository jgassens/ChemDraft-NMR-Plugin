# Reports archive

Archived outputs, numbered to match the assignment that produced them
(`0001-*` ↔ `prompts/01-*`). `0000` is reserved for reviews/audits not tied
to an assignment.

After filing a report here: update `STATUS.md` (milestone table, assumption
ledger, open decisions), graduate any resolved decisions into `decisions/`,
and fix `PLANS.md`/`AGENTS.md` wherever the report contradicts them. A
report that contradicts the plan wins — the plan gets corrected, not the
report.
