# Archive note

These are the planning, status, decision and report records written while the NMR plugin was developed inside the ChemDraft monorepo in July 2026. They were copied here from that repository's `docs/nmr-plugin-planning/` at commit `648e4cb` on 2026-10-07 and removed there. They are a historical record, kept unedited, so paths and instructions inside them (for example `~/Documents/programming/...`, `apps/desktop/src/MainWindow.tsx`, and build-stamp rules) describe the monorepo as it was, not this repository. The folder's former `AGENTS.md` is kept as `AGENTS.historical.md`, unchanged, so that agent tools which load `AGENTS.md` files automatically do not treat it as instructions; it and `PLANS.md` are historical documents, not instructions for anyone working in this repository.
